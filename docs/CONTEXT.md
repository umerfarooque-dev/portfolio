## There are TWO design systems in this repo

This is the single most important thing to understand before touching any UI.

| | **Current** (most of the site) | **Legacy** (older portfolio) |
|---|---|---|
| Pages | `/`, `/work`, `/services`, `/blog`, `/case-studies`, `/about` | `/projects`, `/projects/[id]`, `/contact` |
| Look | near-black `#080808`, one lime accent `#c8ff00`, no gradients | sky-blue → purple gradients, glassmorphism |
| Components | `AnimatedText`, `ScrollRevealText`, `MediaReveal`, `ProjectImage`, `Magnetic` | `GlassCard`, `Heading`, `Text`, `Button`, `ProjectCard`, `ProjectsSection` |
| Typography | `.t-h1`/`.t-h2`/`.t-h3`/`.t-label` + `text-h1` tokens | `size="xl"` props on `Heading`/`Text` |

**Do not "fix" the legacy pages to match the current system unless explicitly asked** —
that is a redesign, not a cleanup. See `DESIGN_SYSTEM.md` for the full inventory.

## Critical rules

1. **Never hardcode content in a component.** Every component reads from `src/data/`.
2. **Never add a `tailwind.config.js`.** Tailwind v4 tokens go in `@theme` in `globals.css`.
3. **Never edit `src/generated/`.** It is stale generated Prisma output, gitignored, and
   not regenerated by `prisma generate`. Import Prisma types from `@prisma/client`.
4. **Keep server components server.** Only add `"use client"` when the component uses
   hooks, state or browser APIs. `MainLayout` is a server component on purpose.
5. **Honour `prefers-reduced-motion`.** Every animated component already does; use
   `usePrefersReducedMotion()` from `src/hooks/useMediaQuery.ts`.
6. **Run `npx tsc --noEmit && npx eslint src && npm run build`** before claiming done.
   All three are currently clean — keep them that way.

## Things to never change casually

- `src/app/globals.css` `@theme` block — every component depends on these tokens.
- `src/lib/motion.ts` — shared variants; a change ripples across ~15 sections. It is also
  typed specifically to avoid a `type: "spring"` widening error that previously produced
  28 TypeScript failures.
- `src/lib/gsap.ts` — the only place plugins are registered. Registering elsewhere
  double-registers ScrollTrigger.
- `src/components/providers/SmoothScroll.tsx` — Lenis drives GSAP's ticker. Changing the
  wiring breaks every scroll animation at once.
- `src/components/templates/MainLayout.tsx` — wraps all 58 routes.
- `prisma/schema.prisma` — `/projects*` reads from it.
- `AGENTS.md` content inside `<!-- BEGIN:nextjs-agent-rules -->` — regenerated by `next dev`.

## Deployment

Vercel. `postinstall` runs `prisma generate`. Required env vars (see `.env.example`):
`RESEND_API_KEY`, `RESEND_FROM_EMAIL`, `CONTACT_TO_EMAIL`, `NEXT_PUBLIC_SITE_URL`.
`DATABASE_URL` is **not** required. Security headers and CSP are in `next.config.ts`.
CI: `.github/workflows/ci.yml` runs tsc, eslint and build on master/development/deployment.
Full guide: `DEPLOY.md`.
